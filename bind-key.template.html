绑定个人 DeepSeek API Key

完成一次绑定后，以后在飞书里让实验助手整理记录，模型费用就记到你自己的 DeepSeek 账号。只查安全课件或拿空白模板，可以直接回飞书使用。

请从本组管理员提供的链接下载此文件，双击用浏览器打开。每份文件只接受对应机器人实例的绑定码。

在你信任的实验助手的单聊里发“绑定个人Key”，从回复中复制以 LAB1. 开头的完整一行。绑定码十分钟有效。

这是 DeepSeek 发给你的密钥，以 sk- 开头。第一次使用，请登录DeepSeek 官方密钥管理页，创建并复制一个 API Key。只把原始 Key 填进下面的密码框。

点“生成加密凭证”后，下框会出现以“绑定凭证”开头的文字。点“复制凭证”，回飞书粘贴并发送。等机器人回复已保存，手机和电脑都能用。

文件在本机加密，机器人保存加密的 Key，之后代表你调用模型。要解除绑定，在同一单聊发送“解绑个人Key”。
