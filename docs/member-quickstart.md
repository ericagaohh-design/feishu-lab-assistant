# 组员速用｜在飞书记实验、绑定个人 DeepSeek Key

打开团队提供的飞书实验助手，在与机器人的**单聊**里操作。

**想用嘴说？** 助手接收文字消息。可以先听写，核对样品编号、数值和单位后再发送。听写无需绑定 DeepSeek。

- **手机**：如果输入框下方有「语音」，点开后左滑选「语音转文字」，按住按钮说话，松开后点「发送」。没有「语音」时，点输入框，使用手机键盘上的麦克风。
- **电脑飞书**：点输入框，Mac 默认按住 `Fn`，Windows 默认按住右 `Alt`。出现「请说话」后口述，松开即可核对文字。快捷键可在头像 → 设置 → 效率 → 语音输入中查看。[飞书语音输入说明](https://www.feishu.cn/hc/zh-CN/articles/360039394633)
- **想用豆包听写**：先启用豆包输入法，在飞书单聊点输入框，切到豆包键盘，按住手机键盘的空格说话。电脑版使用豆包输入法里设置的语音快捷键。核对转写文字后点发送，助手按原有流程记档。机器人无需配置豆包 API Key。[豆包输入法](https://ime.doubao.com/pc)

## 记一条实验

1. 发 `开始记录 模拟观察`，再发一条口述，例如“模拟样品 A 拍了 3 个视野，原图叫 A01.tif”。
2. 发 `查看记录` 核对，发 `记录完成` 保存到本人知识库目录。机器人会回文档链接。只想练习就发 `取消记录`。

看空白表发 `通用模板`，查安全提醒发 `安全培训`。这两项和基础记录归档都可以在绑定前使用。已启用 GUV 成像模板的团队还可以发 `开始GUV成像记录 模拟观察`，按提示补记样品、视野和原图。

## 让 DeepSeek 帮忙整理

1. 准备自己的 DeepSeek API Key。已有 Key 可直接用，也可以登录个人账号创建。[DeepSeek 的 API Keys 页面](https://platform.deepseek.com/api_keys)
2. 在机器人单聊发 `绑定个人Key`。用**电脑**从回复里的链接下载 HTML 文件，双击文件，用浏览器打开。**第一栏粘贴回复末尾的绑定码**（10 分钟有效），**第二栏粘贴自己的 API Key**。原始 Key 只填在本地文件里。
3. 点「生成加密凭证」→「复制凭证」，把整段 `绑定凭证 …` 发回**同一个机器人单聊**。收到“已为你的飞书账号保存个人 DeepSeek Key”后，可以发 `按通用模板带我记实验` 试用。需要模型整理的内容会发给 DeepSeek，费用记在本人 DeepSeek 账号。

绑定码过期就再发一次 `绑定个人Key`。以后想解除绑定，发 `解绑个人Key`。
